# 旧站功能开源边界清单

日期：2026-07-24  
依据：`知识站开源版-现状分析与目标拓扑-2026-07-23.md`

## 1. 分类规则

| 标签 | 含义 |
| --- | --- |
| `core` | v0.1 主闭环必须具备，默认进入公共核心 |
| `optional` | 通用但不阻塞主闭环，通过 Feature Flag、Provider 或后续模块启用 |
| `private` | 麦当个人业务或商业能力，不进入公共核心，可在独立私有插件实现 |
| `drop` | 不应迁移的重复实现、危险设计、历史页面、真实数据或一次性代码 |

分类针对“能力边界”，不代表旧文件可以直接复制。所有进入新仓的逻辑仍需经过白名单审核、重写、测试和隐私检查。

## 2. Site 与内容展示

| 旧站能力 | 分类 | 开源版处理 |
| --- | --- | --- |
| 站点名称、Logo、域名、主题、页脚 | `core` | 进入 Site 配置，不硬编码个人品牌 |
| 首页课程与系列展示 | `core` | 使用通用 Catalog 数据渲染 |
| 创作者简介与社交链接 | `optional` | 使用可配置 Creator Profile |
| 自定义内容页 | `optional` | 后续提供通用页面能力 |
| 麦当个人履历、照片和活动页面 | `private` | 不进入公共核心 |
| 麦当企业培训和个人销售页 | `private` | 保留在私有站或商业插件 |
| 硬编码课程落地页 | `drop` | 改由通用课程详情页和配置生成 |
| 真实评价、回信、收入复盘和抽奖页面 | `drop` | 不复制，Demo 只使用虚构数据 |
| 固定个人域名、社交账号和客服信息 | `drop` | 用无隐私配置替代 |

## 3. Identity 与账号

| 旧站能力 | 分类 | 开源版处理 |

| 用户禁用状态 | `core` | 进入严格 Schema 并参与会话校验 |
| 管理员受控创建 | `core` | 通过 `create-admin` 或授权管理员完成 |
| 微信网页登录 | `optional` | 作为 External Auth Provider，默认关闭 |
| 微信小程序登录与绑定 | `private` | v0.1 不进入公共核心 |
| API Token | `optional` | 等出现明确公共 API 用例后再实现 |

## 12. 边界结论

公共核心只围绕以下闭环建设：

```text
创作者配置站点并发布课程
  → 用户注册
  → 购买全站会员或单门课程
  → 订单幂等授予 Entitlement
  → 用户安全观看、下载并保存进度
  → 创作者在后台管理内容、交易和学习数据
```

新增旧站能力前，必须先在本清单中找到对应分类；无法归类的能力先更新清单或新增 ADR，再进入实现。
