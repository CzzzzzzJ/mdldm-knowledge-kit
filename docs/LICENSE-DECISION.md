# 许可证决策

当前仓库尚未加入正式 LICENSE。公开发布前需要在以下方向中做出明确选择，并记录 ADR。

## 方案 A：Apache License 2.0

适合目标：

- 最大化使用、集成和商业采用；
- 允许个人和公司基于核心做闭源扩展；
- 希望通过品牌、服务、托管或商业插件形成业务。

优点：传播门槛低，带专利授权条款。  
代价：第三方可以修改后闭源，不必回馈核心代码。

## 方案 B：GNU AGPL v3

适合目标：

- 要求通过网络提供修改版服务的人公开对应源码；
- 更重视公共核心持续回流；
- 接受部分商业团队因合规成本放弃采用。

优点：对托管服务场景的回馈约束更强。  
代价：生态采用和商业集成阻力通常更高。

## 当前建议

如果核心目标是帮助更多 AI 博主快速搭建个人知识站，并通过麦当品牌、教程、咨询、托管和商业插件形成影响力，优先考虑 Apache-2.0。

如果核心目标是避免他人把整套系统改造为闭源 SaaS，而社区扩张速度不是第一优先级，考虑 AGPL-3.0。

正式决策必须由项目所有者确认。
