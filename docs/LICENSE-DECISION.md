# 许可证决策记录

项目已于 2026-07-24 确定公共核心采用 Apache License 2.0，正式决策见 `decisions/0002-open-source-license.md`，完整许可证见仓库根目录 `LICENSE`。

## 方案 A：Apache License 2.0

适合目标：

- 最大化使用、集成和商业采用；
- 允许个人和公司基于核心做闭源扩展；
- 希望通过品牌、服务、托管或商业插件形成业务。

优点：传播门槛低，带专利授权条款。  
代价：第三方可以修改后闭源，不必回馈核心代码。

## 方案 B：GNU AGPL v3

适合目标：

- 要求通过网络提供修改版服务的人公开对应源码；
- 更重视公共核心持续回流；
- 接受部分商业团队因合规成本放弃采用。

优点：对托管服务场景的回馈约束更强。  
代价：生态采用和商业集成阻力通常更高。

## 决策结果

项目选择 Apache-2.0，优先降低采用和商业集成门槛，并允许围绕公共核心发展品牌、教程、咨询、托管和独立商业插件。

AGPL-3.0 作为已评估但未采用的备选方案保留在本文中，供未来重新审视许可证策略时参考。
