# 全新环境安装验收

## AF-03：管理员 1 号初始化与临时凭据

验收时间：2026-08-03

### 隔离方式

- Playwright 全局准备先清空名称以 `_e2e` 结尾的专用 MongoDB 数据库；
- 使用虚构邮箱和密码，不接触真实站长账号；
- 并发初始化后删除临时管理员，再从浏览器完成完整首次开站账号旅程；
- 旅程结束时恢复 E2E 的虚构管理员邮箱、正式密码与 `live` 状态。

### 实测结果

| 验收点 | 证据 | 结果 |
| --- | --- | --- |
| 双邮箱确认 | 不一致返回校验错误，一致邮箱标准化为管理员 1 号账号 | 通过 |
| 随机临时密码 | `randomBytes(18)` 提供 144 bit 随机部分；每次初始化结果不同 | 通过 |
| 明文边界 | MongoDB 只有 bcrypt 哈希；响应 `Cache-Control: no-store`；localStorage 与 sessionStorage 均无临时密码 | 通过 |
| 一次性展示 | 离开创建结果页后无法再次读取原文，重复初始化返回 409 | 通过 |
| 强制激活 | 正式密码前后台 API 返回 403，后台页面跳转 `/admin/activate` | 通过 |
| 密码轮换 | 激活后临时密码登录返回 401，正式密码登录成功 | 通过 |
| 并发创建 | 两个并行首次请求仅一个返回 201，另一个返回 409，数据库只有一个管理员 | 通过 |
| 受控恢复 | 独立数据库验证 `--reset-existing`：旧密码失效、新密码有效、强制激活标记清除、会话数为 0 | 通过 |
| 自动化质量门 | `pnpm check`：20 个测试文件、75 项测试和生产构建通过 | 通过 |
| 浏览器主旅程 | `pnpm test:e2e`：包括新增初始化旅程在内 11 项 Chromium E2E | 通过 |

### 结论

仓库不再提供公共默认管理员或默认密码。部署者输入两次自己的邮箱后，系统生成当前部署
独有的临时凭据；只有完成正式密码轮换，才能进入开站指南和其他后台功能。

## AF-02：唯一 15 分钟启动入口

验收时间：2026-08-03

### 隔离方式

- 从当前工作树复制到全新的 `/tmp` 目录；
- 不复制 `.git`、`node_modules`、构建产物、本地环境变量和运行数据；
- 使用冻结锁文件重新安装 448 个依赖记录；
- 使用独立数据库 `mdldm_af02_quickstart_validation`；
- 不创建或修改任何第三方平台资源；
- 验收后停止临时开发服务器、删除专用测试数据库，并将临时目录移入废纸篓。

本机已有 MongoDB 占用 `27017`，另有无关 Vite 服务占用 `3000`。验收首先证明
`START_HERE.md` 的只读端口定位能够准确发现冲突，且没有自动停止未知进程；随后使用
现有本机 MongoDB 的全新专用数据库和端口 `3221` 完成隔离应用旅程。

### 结论

`START_HERE.md` 和 `AGENT_QUICKSTART.md` 中的唯一旅程可以从无依赖、无本地配置的

没有回显密钥、覆盖有效配置、停止未知进程或接触第三方平台。

## AF-01：pnpm 唯一工具链

验收时间：2026-08-03

### 环境与隔离方式

- macOS / arm64；
- Node.js 22.23.1；
- pnpm 10.14.0；
- 从当前工作树复制到新建的 `/tmp` 隔离目录；
- 不复制 `.git`、`node_modules`、`.next*`、本地环境变量、运行数据和测试产物；
- 在隔离目录重新初始化 Git，只为验证发布审计的文件清单；
- 允许复用本机 pnpm 内容寻址 Store，因此本次是“空项目安装”，不是“冷网络下载测速”。

### 实测结果

| 步骤 | 结果 | 实测 |
| --- | --- | ---: |
| `pnpm install --frozen-lockfile` | 安装 448 个依赖记录；只执行已审核的 `esbuild`、`unrs-resolver` 安装脚本 | 7.91 秒 |
| `pnpm check` | Lint、类型检查、18 个测试文件 / 67 项单测、生产构建全部通过 | 通过 |
| `pnpm release:audit` | 257 个文件、448 个依赖许可证记录通过 | 通过 |
| `pnpm audit --audit-level=moderate` | 无已知漏洞 | 通过 |
| `pnpm test:e2e` | 10 项 Chromium 用户旅程通过 | 1.4 分钟 |

### 结论

仓库当前只有 `pnpm-lock.yaml` 一个锁文件。全新目录可以使用冻结锁文件安装并完成
生产构建、单测、发布审计和安全审计；浏览器 E2E 使用同一套 pnpm 脚本通过。
