# 安全基线

## 1. 身份与会话

- 注册接口忽略并拒绝客户端角色字段；
- 管理员只能通过受控脚本或已授权管理员创建；
- 密码使用成熟的自适应哈希算法；
- 会话 Cookie 显式设置 `httpOnly`、`secure`、`sameSite` 和有效期；
- 写操作采用明确的 CSRF 策略；
- 登录、注册、验证、找回密码和敏感接口有限流；
- 用户禁用状态必须进入正式 Schema 并在每次会话校验。

## 2. 权益与授权

- 所有视频、资料、后台和订单接口默认拒绝；
- 页面展示权限不能替代服务端授权；
- Entitlement 是唯一权益事实源；
- 权益类型、目标、开始和结束时间均可追踪；
- 权益到期、撤销和退款后必须正确回收访问；
- 权限矩阵需要自动化测试。

## 3. 商品与支付

- 客户端只提交 `productId` 和必要购买参数；
- 金额、币种、权益和商品标题由服务端 SKU 计算；
- 回调必须验签；
- PaymentEvent 保存唯一事件键和原始摘要；
- 重复回调不得重复创建订单项或授予权益；
- 支付、订单和授权失败必须可重试、可审计；
- 日志不得保存完整支付密钥或敏感载荷。

## 4. 媒体与上传

- 上传类型、大小、权限和对象键必须校验；
- 文件名不能直接决定存储路径；
- 私有媒体默认不可公开列举；
- 下载和播放 URL 使用短期授权；
- MediaAsset 记录 owner、checksum、状态和 Provider；
- 删除课程前处理引用和孤儿资产；
- 转码完成前保留可回滚的旧媒体。

## 5. 数据与隐私

- 公共仓库、Seed 和测试只使用虚构数据；
- 禁止提交真实邮箱、订单、评价、回信和收入数据；
- 日志最小化个人信息；
- 导出和备份文件默认不进入 Git；
- 文档截图必须经过隐私审核；
- 删除、导出和保留周期必须在发布前文档化。

## 6. 可观测性与告警

- 失败队列只保存排障所需的固定字段和脱敏错误；
- 不记录邮箱、Cookie、Bearer Token、AccessKey、支付回调原文和完整连接凭据；
- 告警 Webhook 必须使用 HTTPS、时间戳和 HMAC 签名；
- 接收端拒绝过期时间戳，并使用常量时间比较签名；
- ErrorReporter 失败不得覆盖原业务错误或回滚支付事实；
- 管理员处理记录不得写入密钥或用户敏感信息。

## 7. 配置与供应链

- 密钥只通过环境变量或 Secret Manager 注入；
- `.env.example` 只包含无效占位值；
- CI 执行类型检查、Lint、测试、构建、依赖和密钥扫描；
- Provider SDK 版本需要锁定；
- 高危依赖升级优先处理；
- Release 必须可追溯到通过质量门的提交。

## 8. 发布阻断条件

以下任一项存在时不得公开发布：

- 仓库包含私有 Git 历史；
- 存在真实用户或业务数据；
- 注册可指定管理员角色；
- 商品金额可由客户端决定；
- 支付回调未验签或不幂等；
- 播放、下载或后台接口存在越权路径；
- 缺少正式 LICENSE；
- 全新环境无法按 README 启动。
