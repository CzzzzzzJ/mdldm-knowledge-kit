# ADR 0002：开源许可证

- 状态：Accepted
- 日期：2026-07-24

## 背景

项目需要在公开发布前从 Apache License 2.0 与 GNU Affero General Public License v3.0 中选择正式许可证。

两者都允许使用、修改和商业活动，但对修改后版本的开放义务不同：

| 维度 | Apache-2.0 | AGPL-3.0 |
| --- | --- | --- |
| 类型 | 宽松许可证 | 强 Copyleft 许可证 |
| 修改后闭源使用 | 允许 | 受限制 |
| 作为网络服务运行修改版 | 不要求公开修改源码 | 必须向该服务的网络用户提供对应源码 |
| 商业集成阻力 | 较低 | 较高 |
| 专利条款 | 明确的贡献者专利授权与终止条款 | 继承 GPLv3 的专利保护体系 |
| 更适合 | 扩大采用、生态集成、托管和商业插件 | 防止公共核心被改造成不回馈源码的闭源服务 |

## 决策

公共核心采用 Apache License 2.0。

选择理由：

1. 优先降低个人创作者和商业团队的采用、集成与二次开发门槛；
2. 允许围绕公共核心发展品牌、教程、咨询、托管和独立商业插件；
3. 保留明确的贡献者专利授权与专利诉讼终止条款；
4. 接受第三方可以在遵守许可证与署名义务的前提下修改、分发并闭源集成。

本决策不授予 `mdldm`、麦当相关名称、Logo 或其他商标的额外使用权。

## 影响

- 仓库根目录加入标准 Apache-2.0 `LICENSE` 文件；
- README 和贡献指南声明公共核心采用 Apache-2.0；
- 如果未来提供与公共核心分离的商业插件，需要单独声明其许可证，不默认继承公共核心策略。
