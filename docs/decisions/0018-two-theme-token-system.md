# ADR 0018：两套白名单主题与语义 Token

- 状态：Accepted
- 日期：2026-08-03

## 背景

公开站已经使用 `--page`、`--surface`、`--ink`、`--accent` 等语义变量，并通过共享组件
复用麦当 mdldm 知识站的 Neo-brutalism 风格，但数据库没有主题事实，页面也不能在不改
代码的情况下切换外观。

第一版只需要保留现有麦当风格并增加一套极简知识库风格。它不是主题商城，也不接受站长
输入任意 CSS、脚本或第三方主题包。

## 决策

1. `modules/site/themes.ts` 提供不含运行时校验依赖的主题目录，SiteSetting 通过服务端
   Schema 保存严格白名单字段 `theme`，当前只接受 `mdldm` 和 `minimal`。
2. `mdldm` 是默认值，延续黄色强调、粗描边、硬阴影和几何课程封面。这里指项目现有的
   麦当 mdldm 视觉语言，不使用麦当劳商标、Logo、字体或受保护素材。
3. `minimal` 使用冷静中性色、单一蓝色强调、细边框、轻阴影和更克制的课程封面。
4. 根布局只把已校验主题写入 `html[data-theme]`。颜色、边框、圆角、阴影和按压反馈由
   `app/globals.css` 的语义 Token 控制；不复制页面和业务组件。
5. 后台 `/admin/site` 可以选择主题。保存后只更新 SiteSetting，并在当前文档根节点应用
   服务端返回的白名单主题。
6. 旧 SiteSetting 没有 `theme` 时安全回落为 `mdldm`，下次保存站点设置时自动补齐字段，
   不要求独立破坏性迁移。
7. 主题不得改变路由、内容结构、表单字段、Product、Order、Entitlement、MediaAsset、
   权限提示或可访问性语义。
8. 两套内置主题只使用 CSS 和现有几何封面，不增加外部图片、字体或许可证负担。

## 备选方案

### 为每套主题复制页面目录

拒绝。它会让业务修复、权限提示和可访问性在多个页面副本之间漂移。

### 允许站长粘贴自定义 CSS

拒绝。任意 CSS 会破坏布局和可访问性，也扩大内容安全与升级兼容范围。

### 第一版引入第三方主题市场

拒绝。主题包版本、资产许可、任意代码和升级协议明显超出当前两主题需求。

## 影响

- 站长可以不修改 TypeScript 切换两套主题；
- 共享语义 Token 成为新增视觉主题的唯一扩展入口；
- 管理后台会继承主题基础 Token，但数据结构和交互流程保持不变；
- 后续新增第三套主题必须加入白名单、补充 Token、深浅模式、移动端和关键旅程测试；
- 创作者杂志主题继续保留为后续可选项，不属于当前完成定义。
