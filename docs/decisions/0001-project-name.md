# ADR 0001：项目英文展示名与仓库名

- 状态：Accepted
- 日期：2026-07-24

## 背景

项目需要一个稳定的英文展示名，用于仓库、README、文档和后续发布。名称既要保留项目来源，也不能让使用者误以为公共核心只能服务于麦当个人站点。

## 决策

- 正式英文展示名使用 `mdldm Knowledge Kit`；
- 仓库名继续使用 `mdldm-knowledge-kit`；
- `mdldm Knowledge Kit` 只用于项目与发行物标识；
- 部署后的站点名称、Logo、域名、主题和创作者信息必须通过 Site 配置修改，不得硬编码为麦当个人品牌。

## 备选方案

### Creator Knowledge Station

名称更通用，但缺少项目来源和已有品牌识别。

### Creator Knowledge Kit

能够表达工具属性，但与当前仓库名和已有文档不一致。

## 影响

- README、包名、镜像名和 Release 使用统一名称；
- Demo 站继续使用虚构品牌，避免把项目名称误当作部署站点名称；
- 若未来进行品牌升级，需要新增 ADR，不直接覆盖本记录。
