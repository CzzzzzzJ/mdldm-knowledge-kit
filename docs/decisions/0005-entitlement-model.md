# ADR 0005：Entitlement 权益模型

- 状态：Accepted
- 日期：2026-07-24

## 背景

原站通过用户 `isVIP`、会员到期时间和课程字段分散判断访问权限。v0.1 同时支持全站会员与单课购买，继续使用布尔字段会形成多个权益事实源。

## 决策

Entitlement 是付费与受控内容访问的唯一权益事实源。

每条权益至少包含：

- `type`：`membership`、`course` 或 `series`；
- `targetId`：单课或系列目标，全站会员为空；
- `startsAt`：生效时间；
- `endsAt`：到期时间，永久权益为空；
- `revokedAt`：撤销时间；
- 后续持久化模型必须记录来源订单、邀请码或管理员操作。

课程访问级别为：

- `public`；
- `registered`；
- `member`；
- `course`；
- `series`。

服务端访问判断顺序：

1. 公开内容直接允许；
2. 其余内容要求有效登录；
3. 登录可看内容直接允许；
4. 有效全站会员可访问受控课程；
5. 单课与系列权益必须匹配目标；
6. 到期或撤销权益一律拒绝。

## 备选方案

### 保留 `isVIP`

无法表达单课、系列、来源、撤销和多段有效期。

### 订单即权益

订单只能描述交易，无法覆盖邀请码、手工授予、退款回收和无支付试用。

## 影响

- 页面展示不得替代服务端 Entitlement 判断；
- Product/SKU 只声明将授予的权益，不直接修改用户角色；
- 支付回调、邀请码和后台操作复用同一授予用例；
- 权限测试必须覆盖未登录、会员、单课、到期和撤销；
- Mongoose 持久化模型在 Phase 3 实现，当前 Phase 1 先提供纯领域规则与单元测试。
